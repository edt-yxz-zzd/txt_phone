===
# ord.awk --- do ord and chr

# Global identifiers:
#    _ord_:        numerical values indexed by characters
#    _ord_init:    function to initialize _ord_
#
# Arnold Robbins, arnold@skeeve.com, Public Domain
# 16 January, 1992
# 20 July, 1992, revised

BEGIN    { _ord_init() }

function _ord_init(    low, high, i, t)
{
    low = sprintf("%c", 7) # BEL is ascii 7
    if (low == "\a") {    # regular ascii
        low = 0
        high = 127
    } else if (sprintf("%c", 128 + 7) == "\a") {
        # ascii, mark parity
        low = 128
        high = 255
    } else {        # ebcdic(!)
        low = 0
        high = 255
    }

    for (i = low; i <= high; i++) {
        t = sprintf("%c", i)
        _ord_[t] = i
    }
}
function ord(str,    c)
{
    # only first character is of interest
    c = substr(str, 1, 1)
    return _ord_[c]
}

function chr(c)
{
    # force c to be numeric by adding 0
    return sprintf("%c", c + 0)
}

  ===
  BEGIN         { <ACTION> }
  <PREDICATE>   { <ACTION> }
  <PREDICATE>   { <ACTION> }
  ...
  <PREDICATE>   { <ACTION> }
  <PREDICATE>   { <ACTION> }

  END           { <ACTION> }

    自定义啥是行#line
        #使用正则表达式:应该是ERE(egrep) 基本无需『\\』
        #但是 有了 行 才有 ^$
        #所以 此时未有『^』『$』#也许是 全文件起讫？
    自定义啥是词#field
        #称之为：词<<==感觉跟shell.word差不多，是个 基础对象类型
  ===
  处理每一行
    应用所有:
      <PREDICATE> { <ACTION> }
    注意:就地修改:'{ gsub("\\s+", " "); print($0) }'
      $0 : 当前行{就地修改进行中}
      $1 : 当前行首词{就地修改进行中}
      $2 : 当前行次词{就地修改进行中}
  ===
  结束动作
  ===

注意事项牜正则表达式:here

注意:『.』含『\n』
  即:(?a)DOTALL: 『.』含『\n』
  需要不含，则改用『/[^\n]/』或『"[^\\n]"』或『"[^\n]"』

注意:不支持『"\\d"』『/\d/』
  但允许『"\\w"』『/\w/』
  但允许『"\\s"』『/\s/』
  ERE/egrep
  #gawk: warning: regexp escape sequence `\d' is not a known regexp operator

注意:全文模式:『^』 『$』是 『\A』 『\Z』 全文起讫，不受 『\n』 影响
  vs:(?m)MULTILINE: 『^』 『$』 受 『\n』 影响 而 不再是 『\A』 『\Z』 全文起讫

注意: bash 『... <<<'here_string'』相当于 『echo 'here_string' | ...』，即 后附个『\n』

注意:不支持『\U』
  使用『\u』表达所有字符，负载长度不固定

注意:RS的情形很复杂
  虽然很多正则表达式有效，但有的又无效
  单『.』无效
  其他情形尚未发现无效

  可行:"[\\0-\\u10FFFF]"
  可行:"[\\0-\\x7f]"
  可行:"[\\0-\\u80]"
  不行: "[\\0-\\x80]"

RS缺省值为『\n』而非 任意空格，也非 连续多个换行符
  FS缺省值 至少 包含 空格、TAB、NEWLINE
  FS缺省值为『[[:space:]]+』而非单个空格

  空的RS=>全文单行 而非 每字符一行，也非使用缺省值
  空的FS=>每字符一栏 而非 全行单栏，也非使用缺省值
