1989:'Addition chains using continued fractions(1989)(Bergeron).pdf'
  x**a --> x**a*y**b
    即:求:加列链{[向量.维度==2]}#二维向量链
  辗转相除法-连分数
    简单地说，就是归组:
      # (*^)类型:系数向量 *^ 单位向量
      [(a,b) *^ (1,1)
      == (a,b)
      == (b*q+r,b)
      == (b*q,b)+(r,0)
      == b*(q,1)+r*(1,0)
      == (b,r) *^ ((q,1),(1,0))
        #归组，更换单位
      ]
      [x**a * y**b
      == x**(b*q+r) * y**b
      == (x**(b*q) * y**b) * (x**r * y**0)
      == (x**q * y**1)**b * (x**1 * y**0)**r
      == X**b * Y**r
        #归组，更换基变量
      ]
      加列链{[a,b]} -[递降归结为]-> (加链{q},加列链{[b,r]})
