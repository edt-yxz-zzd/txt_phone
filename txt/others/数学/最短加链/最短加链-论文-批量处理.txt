  加链-->有向无环图{允许重复边}{连通}{非空}
  对偶图:反向化所有边
  [点.值==总路径数{源点-*->点}]
    =>[靶值{加链{对偶图{原图}}} == 靶值{加链{原图}}]
    =>[靶值{加链{对偶图{简化图}}} == 靶值{加链{简化图}}]
  原图{最短加链}=>[点.出度>=1*[点=!=靶点]]
  原图=>[点.入度==2*[点=!=源点]]
  原图=>[显链长==总点数-1][总边数==2*(总点数-1)]

  简化图{原图}:消除 介点/出度为1的点
  原图or简化图=>[显链长==总边数-总点数+1]
    此等式 在消除介点的过程中 保持不变
      !! 每次消除一个介点及其唯一出边，其俩入边 重接 介点的唯一出边的讫点
  简化图{最短加链}=>[点.出度>=2*[点=!=靶点]]
  简化图=>[点.入度>=2*[点=!=源点]]

  [参与度{u,v} =[def]= 边数{u-1->v}]
  简化图{最短加链}=>[参与度{u,v} <= 3]
    !! (4*x --> 2*2*x) 减少加次(3-->2)
  简化图{最短加链}=>[[3==len{u,v,w}] -> [[参与度{u,w} <= 1]or[参与度{v,w} <= 1]]]
    即 每个点的入重边至多出现一次
      (u+u+...+v+v) -> w
      不如:
      (u+v) -> m
      (m+m+...) -> w
    <==>简化图{最短加链}=>[[3==len{u,v,w}] -> [参与度{u,w} >= 2] -> [参与度{v,w} <= 1]]
    !! 对偶图
    => 每个点的出重边至多出现一次
      (w+w+...) -> u
      (w+w+...) -> v
      不如:
      (w+w) -> m
      (m+...) -> u
      (m+...) -> v
    简化图{最短加链}=>[[3==len{u,v,w}] -> [参与度{w,u} >= 2] -> [参与度{w,v} <= 1]]

    两点版:两点至多合作一次
    简化图{最短加链}=>[[4==len{u,v,w,t}] -> [[参与度{u,t} >= 1][参与度{v,t} >= 1]] -> [[参与度{u,w} == 0]or[参与度{v,w} == 0]]]
    <==>简化图{最短加链}=>[[4==len{u,v,w,t}] -> [[参与度{u,t} >= 1][参与度{v,t} >= 1]] -> [参与度{u,w} >= 1] -> [参与度{v,w} == 0]]
      #无需另列对偶版因为本身已然对称:简化图{最短加链}=>[[4==len{u,v,w,t}] -> [[参与度{t,u} >= 1][参与度{t,v} >= 1]] -> [参与度{w,u} >= 1] -> [参与度{w,v} == 0]]


  [缩水最短加链=[def]=缩水加链{简化图{最短加链}}]
  缩水最短加链=>[[总点数>=2] -> [缩水最短加链[1] <- {2,3}]]
    # 『3』 <==> 原最短加链『值2』是 介点 <==> 缩水最短加链 不含『值2』 #1然后3 跳过2
  [总小步数{靶值} =[def]= 显链长{靶值} - floor_log2(靶值)]
    #s(u)
    #num_small_steps_of_(靶值)
    #最短加链复杂度{靶值}
    #小步:即 未跨至下一个二幂的显节点
  #最短加链的源点最大出度的下界:
  缩水最短加链=>[[总小步数{靶值}>=1] -> ?[vs::缩水最短加链{靶值}] -> [vs[0].出度 >= 3]]
    <==>若靶值非二幂则存在某一最短加链其隐节点总参与度大于二
        !!若靶值非二幂则其最短加链某一非末节点总参与度大于二
        !!非所需加链的领头的翻倍可后移，仍然得到最短加链
  #源点最大出度的下界:
  缩水最短加链=>[[总小步数{靶值}>=2] -> [@[vs::缩水最短加链{靶值}] -> [vs[1] == 3]] -> ?[vs::缩水最短加链{靶值}] -> [vs[0].出度 >= 4]]
    <==>若是靶值阳爻数大于二丶其最短加链皆以二值点为介点则存在某一最短加链其隐节点总参与度大于三
      否则:其最短加链隐节点皆总参与度小于四
        !! 以二值点为介点
        其最短加链隐节点皆总参与度大于二
        其最短加链隐节点皆总参与度等于三
        靶值必是三的倍数
        !! 其最短加链隐节点皆总参与度等于三、以二值点为介点
        其最短加链的领头俩点可后移，仍然得到最短加链
        不断后移 => 其最短加链必是 [1,  2,3,  6,9,... 2*3**k,3**(1+k), ...] 所有 (2*3**k)都是介点，所有(3**k)出度都为(0|3)
        靶值必是三幂
        !! 靶值阳爻数大于二
        [靶值 >= 7]
        [log3(靶值) > 1]
        !! 靶值必是三幂
        [log3(靶值) == ceil_log3(靶值) >= 2]
        但是 加链[1,2,3,6,9,...]{以2,6为介点}{1,3出度为3} 不可能是 最短加链
          因为可更短[1,2,4,8,9,...]
        由此反证
  #缩水最短加链的节点出入度的上界:
  缩水最短加链=>[@[vs::缩水最短加链{靶值}] -> @[j:<-[0..<len(vs)]] -> [vs[j].出度-2 <= 总小步数{靶值}]]
    !! 对偶图
    <<==:
  缩水最短加链=>[@[vs::缩水最短加链{靶值}] -> @[j:<-[0..<len(vs)]] -> [vs[j].入度-2 <= 总小步数{靶值}]]
    每次 加法 不是 大步 就是 小步
    同一讫点=>越多加数是介点，则占用越多小步份额
    #bug:同一讫点&&排序加数使得大数先加=>除了第一次加法可能是大步外，其余都是小步
    最短加链us#非:缩水最短加链vs
    [已占用小步数{us;0-->j}
    == floor_log2(2**j)-floor_log2(us[j])
    == j-floor_log2(us[j])
    ]
    [已占用小步数{us;i-->j}
    == floor_log2(2**(j-i)*us[i])-floor_log2(us[j])
    == (j-i) + floor_log2(us[i])-floor_log2(us[j])
    == (j-floor_log2(us[j])) -(i-floor_log2(us[i]))
    == 已占用小步数{us;0-->j} -已占用小步数{us;0-->i}
    ]
    [s:=总小步数{靶值}][k:=加次乊{越过介点;us;j}=us[j].入度-1][k>=2]:
      ??us[j].入度??应当是vs中相应的入度??
      [j<2*k-2]:
        !! k次加法
        (k+1)个加数(可能重复)
        至少(k-1)个不同加数
        至少(k-1)个不同叉点
        !! k次加法
        略过(k-1)个介点
        j前面至少(k-1)个不同叉点、(k-1)个不同介点
        us[:j]含至少2*(k-1)个不同节点
        [j>=2*k-2]
        _L
      [j>=2*k-2]
      [i:=j-k]
      xx:!! k,j,i,us[i] 固化
      xx:为了降低:已占用小步数{us;i-->j}，只能尽可能增大us[j]
      !! k,j,i 固化
      为了降低:已占用小步数{us;0-->j}，只能尽可能增大us[j]
      [us[j]
      !! [k>=2][j>=2*k-2]
      :> 加次=k,加数数目=(k+1)
      <= 3*us[i] + sum[us[i-t] | [t:<-[1..=k-2]]]
      <= 3*2**(i) + sum[2**(i-t) | [t:<-[1..=k-2]]]
      == 4*2**(i) -2**(i-(k-2))
      == 2**(i+2) -2**(i+2-k)
      == 2**(j+2-k) -2**(j+2-2*k)
      ]
      [len(us)-1==显链长{靶值} == s+floor_log2(靶值)]
      [靶值==us[-1]
      ==us[s+floor_log2(靶值)]
      <= 2**(s+floor_log2(靶值)-j)*us[j]
      !! [us[j] <= 2**(j+2-k) -2**(j+2-2*k)]
      <= 2**(s+floor_log2(靶值)-j)*(2**(j+2-k) -2**(j+2-2*k))
      ]
      !! [k>=2]
      存在介点，并非都是翻倍
      靶值非二幂
      [靶值 > 2**floor_log2(靶值)]
      [s >= 1]
      [1
      < 靶值/2**floor_log2(靶值)
      <= 2**(s-j)*(2**(j+2-k) -2**(j+2-2*k))
      == (2**(s+2-k) -2**(s+2-2*k))
      == 2**(s+2-k)*(1 -2**(-k))
      == 2**(s+2-k)/(2**k/(2**k -1))
      ]
      [2**(s+2-k) > (2**k/(2**k -1)) > 1]
        # [k==2] => 4/3
        # [k==3] => 8/7
        # [k==4] => 16/15
        # [2**(s+2-k) >= 2] 既是必需，又是充分{足够应付任意k>=2}
      [(s+2-k) >= 1]
      [k <= (s+1)]
      !! [k>=2]#存在介点
      [2 <= k <= s+1]
      [s >= 1]
    !! [k>=2] => [k <= s+1]
    !! [k>=1]
    !! [s>=0]
    [加次k <= (s+1)]
    [入度==1+加次k <= (s+2)]
