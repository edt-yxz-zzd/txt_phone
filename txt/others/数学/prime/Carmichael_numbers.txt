===
Schinzel noted in 1959 that
  for every c >= 2 the smallest pseudoprime m_[c] in base c satisfies necessarily m_[c] <= 561.
    Moreover, there exists c such that m_[c] == 561.
    Explicitly, let p_[i] (i = 1,..., s) be the primes such that 2 < p_[i] < 561;
      for each p_[i]
        let e_[i] be such that (p_[i]**e_[i]) < 561 < p_[i]**(1+e_[i]);
        let g_[i] be a primitive root modulo (p_[i]**e_[i]) and,
        by the Chinese remainder theorem,
        let c be such that c == 3 (mod 4) and c == g_[i] (mod (p_[i]**e_[i])) for i = 1, ..., s.
      Then m_[c] == 561.
