  Algorithm 9.6.5 (Evaluation of polynomial on arithmetic progression).
    (The method attains its best efficiency when n is much greater than D.)
  输入:(cs, x0, d, n)
      [xs := range(x0, x0+d*n, d)]
      or:
      [xs := [x0+d*j | [j:<-[0..<n]]]]
  输出:j2y/[y]{len==n}
  耗时:O(D*(D+n))
      [D ~= lnD**2] => [D ~= 16]



#一：求前D个点 用于 初始化 差分表:
  [j2y[:D] := [poly_eval_(cs, x) | [x:<-xs[:D]]]]
    # 蛮力=>O(D**2)
    # 无用:花哨=>O(D*lnD) # <<== "arbitrary" version
#二：制差分表
  [k2diff[:D] := j2y[:D]]
  ... # O(D**2)
#三：累加输出
  ... # O(D*n)

1. [Evaluate at first D points]
    for (0 <= k < D)
        k2diff[k] := f(x0 + k*d);
          #初始化 差分表 而非 j2y[:D]
2. [Create difference tableau]
    for(1 ≤ j < D) {
        for(D-1 ≥ k ≥ j)
            k2diff[k] -= k2diff[k-1];
    }
3. [Operate over tableau]
    j2y[0] := k2diff[0];
    for(1 ≤ j < n) {
        j2y[j] := j2y[j-1] + k2diff[1];
        for(1 ≤ k < D-1)
            k2diff[k] += k2diff[k+1];
    }
    return j2y[:n]

Algorithm 9.6.7
Algorithm 9.6.7 (Evaluation of a polynomial at arbitrary points).
  简化假设:[n==D==2**k]
  This algorithm, via a recursive function eval, returns all the values of f(xs[j]) for arbitrary points xs[0],...,xs[n−1].
  For convenience, we assume D = 2**k, yet simple options will generalize to other D.
0.  预备构造 翻倍增长的多项式树:
    [poly_tree :: {(i,j): if i+1==j then (X-xs[i]) else poly_tree[(i,(i+j)//2)]*poly_tree[((i+j)//2,j)]}}]
1.  [Set breakover]
    δ = 4;// Or whatever classical evaluation threshold is best.

2.  [Recursive eval function]
    def eval(cs,i,k) {
3.  [Check breakover threshold for recursion exit]
        // Next, use literal evaluation at the tiin small cases.
        if((len_xs:=k-i) ≤ δ) {
            xs_ik = xs[i:k]
            return [poly_eval_(cs;x) for x in xs_ik]
        }
4.  [Split the signal into halves]
        j = i+(k-i)//2
5.  [Assemble half-polynomials]
        f_ij = poly_tree[(i,j)]
        f_jk = poly_tree[(j,k)]
6.  [Modular reduction]
        csL = poly(cs) % f_ij;
        csR = poly(cs) % f_jk;
        return eval(csL,i,j) ++ eval(csR,j,k);
    }
